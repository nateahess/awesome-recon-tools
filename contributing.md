# Contribution Guidelines

Thanks for helping improve Awesome Recon Tools. Contributions should keep the list focused, current, and useful.

## Adding or Updating an Entry

- Prefer one commit per suggestion. Multiple commits in a pull request are acceptable when they represent separate changes.
- Use a clear commit message such as `Add tool-name`, `Update tool-name`, or `Remove tool-name`.
- Keep entries alphabetized within their section.
- Use an existing section when possible. Add a new section only when the entry does not fit an existing category.
- Use this format: `- [Item Name](https://example.com) - Description.`
- Start each description with an uppercase character and end it with a period.
- Keep descriptions objective, concise, and specific about what the tool or resource does.
- Do not hard-wrap Markdown lines at a fixed column width.
- Avoid duplicate entries. Place each tool where it makes the most sense.
- Prefer the canonical project website, documentation, or repository URL.
- Verify that links resolve and that the entry still matches the current project or service.
- Do not add archived, deprecated, clearly unmaintained, or undocumented projects to the main README.
- Prefer quality over quantity. This is a curated list of noteworthy reconnaissance and footprinting resources, not an exhaustive directory.
- Use consistent product naming, spelling, punctuation, and terminology.
- Do not add promotional copy, referral links, tracking parameters, or marketing taglines.

## Pull Requests

Before opening a pull request:

- Review the current README to make sure the entry is not already listed.
- Confirm that the project is active and useful for reconnaissance, footprinting, OSINT, or closely related workflows.
- Make sure the README remains consistently formatted and alphabetized.
- Keep the pull request focused on the proposed changes.

By submitting a pull request, you agree to release your contribution under the repository's [CC0 license](LICENSE).

For broader formatting and curation guidance, also review the [Awesome list guidelines](https://github.com/sindresorhus/awesome/blob/main/pull_request_template.md).
